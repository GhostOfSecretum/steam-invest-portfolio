Link to SkinsHead

On the site, open your portfolio and click “Extension code”. The code is valid for 5 minutes.

Signing in with a QR code gives this tab a Steam token. It stays only in memory while the reading runs, is never saved, and is never sent to SkinsHead — only the item list is. The token is revoked at Steam after reading. If you close the tab mid-reading, it is not revoked: remove the device “SkinsHead Browser Extension” in Steam → Settings → Security → Authorized devices.

Scan the code in the Steam mobile app and confirm the sign-in.
