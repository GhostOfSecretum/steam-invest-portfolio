3D-модели для экрана загрузки инвентаря

Три процедурных варианта на three.js (без текстур и внешних моделей). Каждый переиспользует текущую логику лоадера: три шага «Читаем инвентарь → Сверяем цены → Строим аналитику» и симулированный прогресс 3 → 96 → 100%. Клик по карточке открывает вариант во весь экран.

V1

Case Unlock

Металлический кейс с неоновым швом. По мере прогресса крышка открывается, изнутри вылетают карточки предметов (цвета редкости) и встают на орбиту.

  • rounded box
  • orbit cards
  • particles
  • progress ring
V2

Inventory Index

27 ячеек-предметов слетаются из хаоса в куб 3×3×3. Сканирующая плоскость подсвечивает слои, угловые скобки фиксируют «захват» когда индекс собран.

  • 27 cells
  • scan plane
  • wire cage
  • HUD brackets
V3

Market Orbit

Монета с эмблемой-свечами (наш логотип) в центре, вокруг кольцо 3D-свечей растёт вслед за прогрессом, а по их вершинам «отрисовывается» линия цены.

  • brand coin
  • 28 candles
  • price ribbon
  • polar grid
